# 🛡️ Setting Up Safe Windows 11 Laptops for Kids  
### (Using Microsoft Family Safety + Google Family Link)

This guide walks you through setting up three Windows 11 laptops for your children so they’re protected, school‑ready, and properly supervised.

---

# ⚠️ Important Note

**Google Family Link alone cannot manage Windows 11 laptops** (it mainly supports Android and Chromebooks).  

✅ The correct approach is to use:
- **Microsoft Family Safety** → controls the *device itself*  
- **Google Family Link** → controls *Google services (YouTube, Chrome, etc.)*

---

# ✅ Part 1 — Configure Windows 11 Protection (Primary Layer)

## 1. Create a child account on each laptop

On each laptop:

1. Open **Settings → Accounts → Family**
2. Click **Add someone**
3. Select **Create one for a child**
4. Follow the prompts to create their Microsoft account

---

## 2. Sign the child into Windows

- Log into Windows using their new child account
- This links the device to your Microsoft Family controls

---

## 3. Configure controls

Go to: https://family.microsoft.com

### ✔ Screen time limits
- Daily usage caps  
- Bedtime hours

### ✔ Content filtering
- Block inappropriate websites  
- Safe search enabled

### ✔ App & game controls
- Age restrictions  
- Require approval for installs

### ✔ Activity monitoring
- Weekly activity reports

---

## 4. Lock down each laptop

- Parent = Administrator  
- Kids = Standard users  
- Enable Windows Update + Defender

---

# ✅ Part 2 — Google Family Link Setup

## 1. Create Google accounts
Go to https://families.google or use Family Link app

## 2. Install Family Link
Install on your phone (iOS or Android)

## 3. Sign into Chrome
- Open Chrome
- Log in with child's account
- Enable sync

## 4. Configure controls

### ✔ Content filtering
- SafeSearch ON
- YouTube restrictions

### ✔ Website controls
- Allow/block specific sites

### ✔ App approvals
- Manage downloads

---

# ✅ Recommended Architecture

- Microsoft Family Safety → Device control
- Google Family Link → Content control
- Windows Defender → Security

---

# ✅ Extra Safety Tips

- No admin rights for kids
- Control browser installs
- Monitor weekly reports
- Allow school tools, restrict games during school

---

# ✅ Checklist

- [ ] Create Microsoft child account  
- [ ] Log child into Windows  
- [ ] Add to Microsoft Family  
- [ ] Set limits and filters  
- [ ] Install Chrome + sign in  
- [ ] Enable Family Link  
- [ ] Remove admin access  

---

✅ You now have a layered and secure setup for your kids' laptops.
