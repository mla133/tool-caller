# 🏫 School Hours Lock-Down Configuration for Kids' Windows 11 Laptops
### (Structured System for Focused Learning Time)

This guide provides a more advanced configuration that enforces a **school-day structure**, limiting distractions during learning hours while allowing flexibility afterward.

---

# 🎯 Goals of This Setup

- Enforce strict focus during school hours
- Allow educational apps and websites only
- Automatically relax restrictions after school
- Prevent bypassing controls

---

# ⏰ Step 1 — Define School Schedule

Example schedule (adjust as needed):

- School hours: **8:00 AM – 3:00 PM (Mon–Fri)**
- Allowed usage outside: 3:00 PM – 8:30 PM
- Device lock (bedtime): 8:30 PM – 7:00 AM

---

# 🪟 Step 2 — Configure Screen Time (Microsoft Family Safety)

Go to:
https://family.microsoft.com

For each child:

### ✔ Set daily schedule
- Allow login only between **7:00 AM – 8:30 PM**
- Block device entirely overnight

### ✔ Set total time limits
- 6–8 hours (enough for school + homework)

### ✔ Fine-tune weekdays vs weekends
- Stricter weekday schedule
- More relaxed weekend limits

---

# 🚫 Step 3 — Block Distractions During School Hours

## Option A (Recommended): Block specific apps

In Microsoft Family Safety:

- Block games (Minecraft, Roblox, Steam, etc.)
- Block entertainment apps
- Allow only:
  - Browser (Edge/Chrome)
  - Office apps (Word, Excel)
  - School tools (Zoom, Teams)

---

## Option B (Advanced): Time-based blocking strategy

Manual approach:

- During school hours:
  - Disable games and non-educational apps
- After 3:00 PM:
  - Allow access again

(Note: This is managed indirectly via app approvals and time extensions.)

---

# 🌐 Step 4 — Lock Down Web Access

## Microsoft Family Safety

- Turn ON web filtering
- Block adult content
- Create an **allowed list**:
  - school domains (e.g., Google Classroom, school portals)

---

## Google Family Link

In the app:

### ✔ Enable
- SafeSearch
- Restricted YouTube mode

### ✔ Allowed sites example
- docs.google.com
- classroom.google.com
- khanacademy.org

### ✔ Block types
- Gaming sites
- Streaming platforms

---

# 🔐 Step 5 — Prevent Workarounds (Critical)

On each laptop:

- Kids are **Standard users only**
- Require admin password for:
  - Software installs
  - Browser installs

### Lock these down:
- Disable installing new browsers
- Prefer **one browser only** (Edge or Chrome)

---

# 📚 Step 6 — Create a “School Mode” App Allowlist

✅ Allow:
- Microsoft Word / Excel
- Google Docs / Classroom
- Zoom / Teams
- Web browser (controlled)

❌ Block during school hours:
- Games
- Discord / chat apps (optional)
- Streaming services

---

# 📊 Step 7 — Monitor and Adjust Weekly

Review reports in Microsoft Family Safety:

- Screen time trends
- Websites visited
- Apps used

Make adjustments as needed.

---

# ✅ Example Daily Behavior

## 🟢 8:00 AM – 3:00 PM
- Only school apps work
- Gaming and distractions blocked

## 🟡 3:00 PM – 8:30 PM
- Relaxed access
- Limited entertainment allowed

## 🔴 8:30 PM – 7:00 AM
- Device locked

---

# ✅ Advanced Optional Enhancements

- Create separate browser profiles (school vs personal)
- Use DNS filtering (e.g., OpenDNS / Family Shield)
- Use router-level blocking for stronger enforcement
